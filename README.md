# AutoFix Workshop - GRC Project

This repository contains the final executive summary and handover guide for the AutoFix Workshop security project. It's meant to give the shop owner a clear, plain-language overview of the work done and how to keep it up going forward.

## What's in This Repo
- **executive-summary.md** - a plain-language overview of the assets, top risks, and policies put in place
- **handover-guide.md** - practical instructions for reviewing and updating the inventory, risk register, and policies going forward (including an annual review checklist)

## Full Project History
This handover builds on three earlier stages of the project, each in its own repository:
1. [Asset Inventory](https://github.com/aleezakhannn/autofix-workshop-asset-inventory) - hardware, software, and data store inventory
2. [Risk Register](https://github.com/aleezakhannn/autofix-workshop-risk-register) - top threats scored by likelihood and impact, with NIST CSF-mapped controls
3. [Security Policies](https://github.com/aleezakhannn/autofix-workshop-security-policies) - Acceptable Use Policy and Password/Access Control Policy for staff

## Who This Is For
This repository is written for the AutoFix Workshop owner/manager - no technical background required to understand or maintain what's here.
