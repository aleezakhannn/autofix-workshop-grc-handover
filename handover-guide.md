# AutoFix Workshop - Handover Guide

This guide explains how to keep the security work up to date after this project is complete. No technical background is needed - just a few simple habits done on a regular schedule.

## Updating the Asset Inventory
- Add new equipment (computers, scanners, devices) to the inventory as soon as it's purchased.
- Remove or mark as "Retired" any equipment that's no longer used, and make sure old devices are wiped before disposal.
- Review the full inventory at least **once a year** to make sure it still reflects what's actually in the shop.

## Reviewing the Risk Register
- Revisit the risk register **once a year**, or sooner if something changes significantly (new software, a new payment system, a security incident, etc.).
- Ask: are the same risks still the biggest concern, or has something new come up?
- Update likelihood, impact, or mitigation controls if circumstances have changed.

## Keeping Policies Current
- Review the Acceptable Use Policy and Password/Access Control Policy once a year, alongside the risk register.
- Share any updates with all staff and have new hires read both policies on their first day.
- If a staff member leaves, make sure their access is removed the same day (already covered in the Password policy, but worth double-checking during reviews).

## Who's Responsible
The shop owner/manager should own this review process, even without a dedicated IT person. Setting a yearly reminder (e.g., every January) is an easy way to make sure it doesn't get forgotten.

## Quick Annual Checklist
- [ ] Asset inventory reviewed and updated
- [ ] Risk register reviewed and re-scored if needed
- [ ] Policies reviewed and reshared with staff
- [ ] Any departed staff access confirmed removed
